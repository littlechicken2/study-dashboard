# FreeTCF 划词进入 Anki

## 日常使用

1. 在 FreeTCF 阅读题中双击一个法语单词。
2. 浏览器会直接打开法语助手。
3. 在词典页确认原形和词义。
4. 点击“加入 Anki · 明天复习”。

卡片会进入：

`French Daily Audio + Reading`

如果单词已经存在，扩展不会创建重复卡片，只会将原卡安排到明天复习。

拖动选择文本时仍会显示“查词”按钮，作为短语查询的备用方式。

## 本地连接

- 学习平台：`127.0.0.1:8765`
- AnkiConnect：`127.0.0.1:8766`
- 查询词典不需要打开 Anki。
- 加入卡片时 Anki 必须正在运行，可以最小化到后台。
